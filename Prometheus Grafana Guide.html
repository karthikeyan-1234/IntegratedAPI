.NET API Monitoring with Prometheus & Grafana

Simple Step-by-Step Guide for Real-Time API Monitoring

📋 PREREQUISITES

Ensure you have these running before starting:

  • .NET API running in Visual Studio on https://localhost:7216
  • Docker Desktop installed and running
  • PowerShell with Administrator privileges
    • Important: Make sure your .NET API is configured to expose Prometheus metrics at the /metrics endpoint. This typically requires adding the prometheus-net.AspNetCore NuGet package.

    1 Create Folder Structure

    Open PowerShell as Administrator and run:

    PowerShell Commands
    cd C:\Users\mail2\source\repos\IntegratedAPP\IntegratedAPI
    mkdir Prometheus-Grafana
    cd Prometheus-Grafana
    Note: Adjust the path according to your project location.

    2 Create docker-compose.yml

    Create a new file named docker-compose.yml with the following content:

    docker-compose.yml
    version: '3.8'

    services:
      prometheus:
        image: prom/prometheus:v2.48.0
        container_name: prometheus
        volumes:
          - ./prometheus.yml:/etc/prometheus/prometheus.yml
        ports:
          - "9090:9090"
        extra_hosts:
          - "host.docker.internal:host-gateway"

      grafana:
        image: grafana/grafana:10.2.2
        container_name: grafana
        environment:
          - GF_SECURITY_ADMIN_PASSWORD=admin
        ports:
          - "3000:3000"

    3 Create prometheus.yml

    Create a new file named prometheus.yml with the following content:

    prometheus.yml
    global:
      scrape_interval: 15s

    scrape_configs:
      - job_name: 'dotnet-api'
        scheme: https
        metrics_path: '/metrics'
        static_configs:
          - targets: ['host.docker.internal:7216']
        tls_config:
          insecure_skip_verify: true
    Note: The insecure_skip_verify: true setting is required because we're using a self-signed certificate from localhost.

    4 Start Containers

    Start the Prometheus and Grafana containers:

    PowerShell Command
    docker-compose up -d

    Wait 30 seconds, then check if containers are running:

    PowerShell Command
    docker ps

    Should show both containers running.

    5 Verify Prometheus is Scraping

    1. Open browser: http://localhost:9090
    2. Click Status → Targets
    3. Look for dotnet-api with State: UP (green)
    If the state is DOWN, wait 30 more seconds and refresh the page.

    6 Setup Grafana

    1. Open browser: http://localhost:3000
    2. Login: admin / admin
    3. Click Configuration (gear icon) → Data Sources
    4. Click Add data source
    5. Select Prometheus
    6. Set URL: http://prometheus:9090
    7. Click Save & Test
    Should see "Data source is working" message.

    7 Create Dashboard

    Create Dashboard

    1. Click + (plus icon) → Dashboard
    2. Click Add visualization

    Panel 1 - Request Rate

    1. Query A: rate(http_requests_received_total[1m])
    2. Click Run query (top right)
    3. See if you get data
    4. Click Apply

    Panel 2 - Memory Usage

    1. Click Add panel (top right)
    2. Query A: process_private_memory_bytes / 1024 / 1024
    3. Click Apply

    Panel 3 - Response Time

    1. Click Add panel
    2. Query A: histogram_quantile(0.95, rate(http_request_duration_seconds_bucket[5m])) * 1000
    3. Click Apply

    Save Dashboard

    1. Click Save (top right)
    2. Name: .NET API Metrics
    3. Click Save

    8 Generate Traffic

    In a NEW PowerShell window (regular user, not Administrator), run:

    PowerShell Command
    # PowerShell infinite loop to generate traffic
    while ($true) {
        Invoke-RestMethod -Uri "https://localhost:7216/health" -SkipCertificateCheck
        Start-Sleep -Seconds 1
    }

    Alternative (if Invoke-RestMethod fails):

    PowerShell Alternative
    for (;;) {
        curl.exe -k https://localhost:7216/health
        Start-Sleep 1
    }
    This continuously calls your API to generate metrics data. Keep this running while monitoring. Press Ctrl+C to stop the loop.

    9 Watch Metrics

    Go back to your Grafana dashboard. You should see graphs updating every 15 seconds.

    🎉 Congratulations! You now have live monitoring of your .NET API.
  • ✅ Prometheus scraping .NET API metrics
  • ✅ Grafana connected to Prometheus
  • ✅ Dashboard with 3 key metrics
  • ✅ Live monitoring of your API

    • 🔧 Troubleshooting

    Problem 1: Prometheus target is DOWN

    Test connectivity from the container:

    PowerShell Command
    docker exec prometheus curl -k https://host.docker.internal:7216/metrics

    If this fails, check that your .NET API is running and accessible.

    Problem 2: No data in Grafana

    • Make sure traffic generator is running (Step 8)
    • Wait 1 minute for data to accumulate
    • Refresh Grafana dashboard
    • Verify Prometheus target is UP (Step 5)

    Problem 3: Can't login to Grafana

    Default credentials are: admin / admin

    If you've changed the password and forgotten it, you can reset by:

    PowerShell Command
    docker exec grafana grafana-cli admin reset-admin-password admin
