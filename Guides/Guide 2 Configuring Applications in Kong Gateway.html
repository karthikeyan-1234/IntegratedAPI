Applications to Configure

  • IntegratedAPI: .NET API with Swagger documentation
  • Angular App: Frontend application with base href="/web/"

Register IntegratedAPI Service

3.1 Create Kong Service

Register .NET API Service PowerShell
# Register the .NET API service with Kong Invoke-RestMethod -Uri "https://kong-admin.local/services/" ` -Method POST ` -ContentType 'application/json' ` -Body (@{ name = "integratedapi-service" url = "http://integratedapi-service.default.svc.cluster.local:7080" } | ConvertTo-Json) ` -SkipCertificateCheck
Expected Response: JSON with service details including id and name.

3.2 Create Routes for API

Create API Routes PowerShell
# Create Swagger UI route Invoke-RestMethod -Uri "https://kong-admin.local/services/integratedapi-service/routes" ` -Method POST ` -ContentType 'application/json' ` -Body (@{ name = "integratedapi-swagger-route" paths = @("/swagger") strip_path = $false } | ConvertTo-Json) ` -SkipCertificateCheck # Create API endpoints route Invoke-RestMethod -Uri "https://kong-admin.local/services/integratedapi-service/routes" ` -Method POST ` -ContentType 'application/json' ` -Body (@{ name = "integratedapi-api-route" paths = @("/api") strip_path = $false } | ConvertTo-Json) ` -SkipCertificateCheck # Create WeatherForecast route (example) Invoke-RestMethod -Uri "https://kong-admin.local/services/integratedapi-service/routes" ` -Method POST ` -ContentType 'application/json' ` -Body (@{ name = "integratedapi-weather-route" paths = @("/WeatherForecast") strip_path = $false } | ConvertTo-Json) ` -SkipCertificateCheck
Route Configuration Notes:
  • strip_path = $false: Keeps the path prefix when forwarding to upstream (API expects /swagger, /api)
  • paths = @("/swagger"): Matches /swagger and /swagger/*

3.3 Test IntegratedAPI

Test API Endpoints PowerShell
# Test Swagger UI Invoke-WebRequest -Uri "https://kong-proxy.local/swagger/index.html" -SkipCertificateCheck # Test API endpoint Invoke-RestMethod -Uri "https://kong-proxy.local/api/Employee/GetEmployees" -SkipCertificateCheck # Test WeatherForecast Invoke-RestMethod -Uri "https://kong-proxy.local/WeatherForecast" -SkipCertificateCheck # Browser test: Open https://kong-proxy.local/swagger/index.html

Register Angular Application Service

4.1 Create Kong Service for Angular

Register Angular App Service PowerShell
# Register the Angular app service Invoke-RestMethod -Uri "https://kong-admin.local/services/" ` -Method POST ` -ContentType 'application/json' ` -Body (@{ name = "angular-app-service" url = "http://angular-app-service.default.svc.cluster.local:80" } | ConvertTo-Json) ` -SkipCertificateCheck
Common Mistake: Ensure the port is 80 (nginx default), not 7080 (API port).

4.2 Create Route for Angular App

Create Angular Route PowerShell
# Create /web route with strip_path=true Invoke-RestMethod -Uri "https://kong-admin.local/services/angular-app-service/routes" ` -Method POST ` -ContentType 'application/json' ` -Body (@{ name = "angular-app-route" paths = @("/web", "/web/") strip_path = $true preserve_host = $true } | ConvertTo-Json) ` -SkipCertificateCheck

CRITICAL: Why strip_path=true for Angular?

Your Angular app is built with <base href="/web/">. Here's what happens:

Setting Browser Request Kong Forwards Nginx Looks For Result
strip_path = false /web/main.js /web/main.js /usr/share/nginx/html/web/main.js ❌ 404
strip_path = true /web/main.js /main.js /usr/share/nginx/html/main.js ✅ 200

Bottom line: Kong strips /web before forwarding, but browser still thinks it's at /web/ (correct!).

4.3 Test Angular App

Test Angular via Kong PowerShell
# Test Angular app via Kong Invoke-WebRequest -Uri "https://kong-proxy.local/web" -SkipCertificateCheck # Browser test: Open https://kong-proxy.local/web # You should see your Angular application load with all assets

Common Management Operations

Update a Route

Change Route Settings PowerShell
# Example: Change strip_path setting Invoke-RestMethod -Uri "https://kong-admin.local/routes/angular-app-route" ` -Method PATCH ` -ContentType 'application/json' ` -Body (@{strip_path = $false} | ConvertTo-Json) ` -SkipCertificateCheck

Delete a Route

Remove Route PowerShell
# Delete by route name Invoke-RestMethod -Uri "https://kong-admin.local/routes/angular-app-route" ` -Method DELETE ` -SkipCertificateCheck

Update a Service

Modify Service Configuration PowerShell
# Example: Change service port Invoke-RestMethod -Uri "https://kong-admin.local/services/angular-app-service" ` -Method PATCH ` -ContentType 'application/json' ` -Body (@{port = 80} | ConvertTo-Json) ` -SkipCertificateCheck

Important Reminders

  • PowerShell 7+: Required for -SkipCertificateCheck
  • Service URLs: Must use Kubernetes internal DNS format (service-name.namespace.svc.cluster.local)
  • strip_path: Set to true for Angular apps with base href, false for APIs
  • Conflicting Ingresses: Ensure no other ingress rules conflict with Kong (see Guide 3)
